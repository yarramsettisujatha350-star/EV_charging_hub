## Dynamic Multi-Port EV Charging Hub with Demand-Based Power Allocation

## 📌 Project Overview
An intelligent EV charging system that dynamically allocates power to multiple EVs based on battery demand, using ESP32 and MATLAB/Simulink.

## 🛠️ Technologies Used
- ESP32 Microcontroller
- MATLAB & Simulink
- Embedded C
- IoT & Power Electronics

## ⚡ Key Features
- Demand-based power allocation
- Multi-port simultaneous charging
- Real-time battery monitoring
- MATLAB simulation & hardware validation
